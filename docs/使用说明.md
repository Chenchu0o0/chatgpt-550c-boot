# ChatGPT 启动动画 · 流浪地球2 550C

一个不修改 ChatGPT/Codex 客户端任何文件的启动动画覆盖层：先全屏播放 550C 开机片头，
动画播完后再拉起 ChatGPT（Codex 桌面应用）。双击即可用，删除文件夹即完全卸载。
联网、登录、使用与平时直接打开 ChatGPT 完全一致，脚本不碰任何网络设置。

## 文件结构
- launcher/ChatGPT.cmd          —— 双击运行入口
- launcher/ChatGPT-boot.ps1     —— 启动器主脚本（PowerShell）
- assets/550c-overlay.html      —— 动画本体（浏览器直接打开可预览）
- icons/icon-chatgpt.ico        —— ChatGPT 官方图标（创建快捷方式时用）

## 使用
1. 双击「launcher\ChatGPT.cmd」或运行其中的 PowerShell 脚本
2. 屏幕先播放 550C 片头（默认完整模式，约 90 秒）
3. 动画播完后再打开 ChatGPT，覆盖层关闭

### 模式（可选）
- 完整（默认，约 90 秒，550C 书写后继续播 47 节点覆写全流程，可点击/Esc 跳过）
- 简易（约 5 秒，只播 logo 书写）
- 关闭：不播放动画，直接启动

powershell -NoProfile -ExecutionPolicy Bypass -File "launcher\ChatGPT-boot.ps1" -Mode full
powershell -NoProfile -ExecutionPolicy Bypass -File "launcher\ChatGPT-boot.ps1" -Mode simple
powershell -NoProfile -ExecutionPolicy Bypass -File "launcher\ChatGPT-boot.ps1" -Mode off

### 参数
- -Mode simple|full|off（默认 full）
- -DelaySec 0..N —— 动画结束后、拉起 ChatGPT 前的缓冲秒数（默认 1）

## 创建桌面快捷方式
仓库不包含 .lnk（快捷方式是绝对路径，不适合提交）。按需自建：
1. 右键桌面 → 新建 → 快捷方式
2. 目标填：`C:\Windows\System32\cmd.exe /c ""<本目录>\launcher\ChatGPT.cmd""`
3. 图标可改选 `icons\icon-chatgpt.ico`

## 说明与限制
- 不修改 ChatGPT/Codex 任何文件，不写注册表，无需管理员权限
- 需要本机已安装 ChatGPT 桌面应用（商店版 OpenAI.Codex）以及 Chrome 或 Edge
- 动画播放期间按 Esc 或点击可跳过
- 完整模式最长约 90 秒，覆盖层最长停留 150 秒后自动关闭
- 这是「启动前覆盖层」，不是改客户端本体；官方商店版资源只读，无法安全注入启动画面
